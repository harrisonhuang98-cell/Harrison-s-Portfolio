# Harrison Huang — Portfolio

A responsive personal portfolio for a computer science student interested in biomedical engineering.

## Files

- `index.html`: portfolio content and navigation
- `styles.css`: futuristic theme and centered mobile layout
- `harrison-avatar.png`: personal UFO avatar

This website uses only HTML and CSS. No JavaScript, dependencies, or build step are required.

Open `index.html` in a browser to preview it. Projects, skills, GitHub, and LinkedIn entries are clearly marked placeholders.
